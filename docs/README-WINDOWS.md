# Windows setup for MARKET RADAR

## Prerequisites
1. Install Python 3.11 from https://www.python.org/downloads/
   - Check "Add Python to PATH" during install
2. Install Microsoft Visual C++ Build Tools:
   https://visualstudio.microsoft.com/visual-cpp-build-tools/
   - Select "Desktop development with C++" workload
3. Install Git for Windows: https://git-scm.com/download/win

## Setup
Open PowerShell, then run:
    cd C:\MARKET_RADAR    # or wherever you extracted the tarball
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    python -m pip install --upgrade pip
    pip install -r requirements-windows.txt

## TA-Lib (the tricky one)
If `pip install TA-Lib` fails, download the matching wheel from
https://github.com/cgohlke/talib-build/releases and:
    pip install C:\path\to\TA_Lib-...whl

## Edit .env
Open .env and update any absolute paths from
/Users/sidnerusu/Documents/Claude/Projects/MARKET\ RADAR/
to your Windows path (use forward slashes or escaped backslashes).

## Start the daemon
